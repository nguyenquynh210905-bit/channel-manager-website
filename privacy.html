Privacy Policy

Application: Channel Manager

Last updated: November 7, 2026

1. Introduction

Channel Manager is an independent Windows desktop application designed to help users organize their TikTok accounts and view authorized account and video analytics.

This Privacy Policy explains how information is accessed, processed, stored, and managed when using the application and its website.

2. Information We Process

Depending on the features enabled and permissions granted, Channel Manager may process:

  • TikTok usernames and profile URLs.
  • Account identifiers provided through authorized APIs.
  • Follower counts and profile statistics.
  • Video identifiers and publication information.
  • Video views, likes, comments, and shares.
  • Analytics history and synchronization timestamps.
  • Account connection and synchronization status.
  • API authorization credentials when configured.

The application does not require users to provide their TikTok passwords directly to Channel Manager.

3. How Information Is Collected

Information may be obtained through:

  • TikTok's official APIs, when access has been approved and the user has granted permission.
  • TikTok Local Sync, a browser extension that reads supported information displayed on TikTok pages and sends it to the local desktop application.
  • Information entered by the user directly into Channel Manager.

4. How Information Is Used

Channel Manager processes information to:

  • Display account and video analytics.
  • Organize connected account profiles.
  • Track changes in available statistics.
  • Generate local reports and analytics history.
  • Maintain authorized account connections.
  • Diagnose synchronization errors.

The application is intended for account management and analytics. It does not provide artificial engagement generation services.

5. Data Storage and Security

In the current desktop design, account management records and analytics are stored locally on the user's computer.

Chrome browser profiles maintain their own website sessions and browser data. Channel Manager uses separate profile directories for managed accounts.

When configured on Windows, API credentials stored by the application are protected using Windows data protection mechanisms.

Users should secure their computers and should not share access tokens, session data, passwords, or other sensitive credentials.

6. Third-Party Services

Channel Manager interacts with TikTok services when users access TikTok or authorize API access. TikTok processes information according to its own privacy policies and platform terms.

This website may be hosted through GitHub Pages, which may process technical access information according to GitHub's policies.

7. Data Sharing

The current local desktop workflow does not automatically upload stored analytics to a Channel Manager-operated cloud database.

Data may be exchanged with TikTok when users authorize official API requests or use TikTok services through their browsers.

Channel Manager is not designed to sell users' personal information or analytics data.

8. Data Retention and Deletion

Locally stored account records and analytics remain on the user's computer until they are removed through available application controls or by deleting the relevant local data.

Browser profiles, exported reports, and database backups may require separate deletion.

Users may revoke third-party API permissions through the relevant service's account settings. Revoking access does not automatically delete previously stored local analytics.

9. User Choices

Users can choose which accounts to add, whether to configure API connections, and whether to use the TikTok Local Sync extension.

Users can stop synchronization and disconnect available integrations. Requests concerning data controlled by the application operator may be submitted through the contact information below.

10. Children's Privacy

Channel Manager is not intended for children under the minimum age permitted by applicable platform rules and laws. It is not designed to knowingly collect children's personal data.

11. Changes to This Policy

This Privacy Policy may be updated when the application's features or data practices change. The latest version will be published on this page.
